🍽️ Custom Recipe Generator
An AI-powered tool that generates unique recipes based on available ingredients.

🔹 Overview
This project utilizes AI to create personalized recipes using a list of ingredients provided by the user. The tool leverages Flask for the web interface and Groq's AI to generate creative and delicious meal ideas.

✨ Features
🥗 Ingredient-Based Recipe Generation – Enter available ingredients, and the AI will craft a unique recipe.

🍳 Detailed Output – Get a recipe title, ingredient list, cooking steps, estimated cooking time, and serving size.

🎨 User-Friendly UI – A sleek and modern web interface for easy interaction.

⚡ AI-Powered Responses – Uses Groq’s AI to generate high-quality and creative recipe suggestions.

AI Model: Groq API (LLM-powered recipe generation)

Install dependencies:

pip install flask groq

Run the Flask app:

python app1.py

Access the app in your browser:
👉 http://127.0.0.1:5000/
